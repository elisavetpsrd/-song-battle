SONG BATTLE – Prototype
1. Ανέβασε όλα τα αρχεία σε Node.js project (π.χ. Replit).
2. Τρέξε: npm install και μετά npm start.
3. Άνοιξε το public URL στην TV/κεντρική οθόνη και πάτησε TV / HOST.
4. Στα κινητά ανοίξτε το ίδιο URL, ΚΙΝΗΤΟ / ΠΑΙΚΤΗΣ, γράψτε το ROOM CODE και επιλέξτε TEAM A ή TEAM B.
5. Το πρώτο BUZZ κλειδώνει. Ο Host δίνει πόντο ή κάνει RESET.
6. Από τον Host μπορείς να επιλέξεις δικό σου audio αρχείο και να κάνεις PLAY / STOP.
